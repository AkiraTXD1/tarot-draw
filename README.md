# 静室 · 中文塔罗抽牌

一个可以直接离线运行的中文文字塔罗抽牌小程序。当前是第一阶段：只显示 CSS 牌背和文字牌面，不包含任何卡牌图片，也不会联网。

## 使用方法

1. 将本目录中的 5 个文件保持在一起：
   - `index.html`
   - `style.css`
   - `script.js`
   - `cards.js`
   - `README.md`
2. 双击 `index.html`，使用现代版 Chrome、Edge、Firefox 或 Safari 打开。
3. 问题可以留空。选择牌阵后点击“开始抽牌”。
4. 逐张点击牌背。全部翻开后，可以把记录保存在当前浏览器中。
5. 历史记录位于页面底部，默认折叠。

不需要安装 Node.js、包管理器或任何第三方依赖。程序不调用 AI、API、网络服务，也不加载外部字体、图标或图片。

## 文件职责

- `cards.js`：完整 78 张塔罗数据，只负责牌库。
- `script.js`：安全随机抽牌、正逆位、翻牌、界面状态和本地历史记录。
- `style.css`：牌背、文字牌面、桌面/平板/手机布局和动画。
- `index.html`：页面语义结构和各功能入口。
- `README.md`：使用、扩展和检查说明。

抽牌数据、抽牌逻辑与界面渲染互相分离。图片路径不会参与选牌或正逆位计算。

## 随机机制

程序只使用浏览器的 `crypto.getRandomValues()`：

- 选牌使用加密随机整数，并采用拒绝采样避免直接取模的分布偏差。
- 每抽出一张牌，就从本次临时牌池中移除，因此同一牌阵不会重复。
- 牌的正逆位由另一次独立随机读取决定，理论概率各为 50%。
- 整个牌阵的牌与正逆位，在点击“开始抽牌”的同步流程中一次性确定。
- 问题文本没有传入 `drawCards()`，只用于当前页面显示和保存记录。
- 翻牌动画、卡片点击顺序、窗口尺寸和点击速度都不会重新计算结果。

## 历史记录

历史记录使用 `localStorage`，只保存在打开页面的当前浏览器中。每条记录包含：

- 随机生成的唯一记录 ID
- 日期和具体时间
- 问题
- 牌阵
- 各牌位的牌名、正逆位与关键词

刷新或重新打开页面后，记录会从同一个存储键中重新读取。清理浏览器网站数据、使用隐私模式或更换浏览器会影响这些本地记录。删除单条记录、清空全部记录和放弃当前牌面都需要确认。

## 未来添加卡牌图片

预设卡牌图片目录：

```text
assets/cards/
```

当前不要创建该目录也不影响运行。以后添加图片时：

1. 创建 `assets/cards/` 并放入拥有合法使用权的卡图。
2. 在 `cards.js` 找到对应卡牌定义。
3. 每条卡牌定义最后一个参数目前是 `null`，将它改成相对路径，例如：

```javascript
major(
  0,
  "愚人",
  "The Fool",
  ["开始", "自由", "冒险"],
  ["鲁莽", "迟疑", "缺乏准备"],
  "新的旅程正在展开，以开放的心态迈出第一步。",
  "冲动或过度犹豫都可能让你错失真正的起点。",
  "assets/cards/major-00.webp"
)
```

运行时生成的每张卡牌对象都包含 `image` 字段。统一的 `renderCardFace()` 会在 `image` 有值时加入图片；图片加载失败时会自动移除失败图片，保留完整文字牌面。无需修改随机抽牌逻辑。

未来牌背图片预设为：

```text
assets/card-back.webp
```

当前牌背完全由 CSS 绘制。以后如要使用牌背图片，可在 `style.css` 的 `.card-back` 背景中加入 `url("assets/card-back.webp")`，并保留现有背景色作为加载失败时的回退。

### 测试环境说明

脚本语法、牌库完整性、随机抽样、本地存储往返和外部资源扫描已在本地自动执行。Codex 应用内浏览器的安全策略不允许自动打开 `file://` 页面，因此没有绕过限制进行自动截图式视觉测试；320px 项目采用代码级响应式检查。最终使用时仍建议在目标手机或平板浏览器双击/打开 `index.html` 做一次实机观感确认。
